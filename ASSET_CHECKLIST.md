# Client Asset Checklist

Request these from PRO EVENTS CAIRNS before final launch.

## Brand assets
- [ ] Logo (SVG preferred, or high-resolution transparent PNG)
- [ ] Brand colors, if already established
- [ ] Preferred fonts, if any
- [ ] Correct company spelling and approved tagline

## Event photography and video
- [ ] Hero image or short muted hero video
- [ ] Sound-system setup photos
- [ ] Stage-lighting photos
- [ ] LED-wall photos
- [ ] Decoration photos
- [ ] Birthday event photos
- [ ] Holy Communion photos
- [ ] Wedding and engagement photos
- [ ] Cultural event photos
- [ ] Corporate event photos
- [ ] Large/mega event photos
- [ ] Behind-the-scenes or team photos
- [ ] Permission to publish every supplied image/video

## Package details
- [ ] What exactly is included in the $300 starting price?
- [ ] Is $300 a minimum package price, a hire price, or a starting estimate?
- [ ] Actual package options and inclusions
- [ ] Travel or delivery fees, if applicable
- [ ] Setup and pack-down terms
- [ ] Deposit, cancellation, and payment policies
- [ ] How custom quotes are requested and confirmed

## Business details
- [ ] Confirm Cairns and service area coverage
- [ ] Confirm whether each phone number supports WhatsApp
- [ ] Business email, if available
- [ ] Street address, only if it should be public
- [ ] Approved social media URLs
- [ ] Approved testimonials and permission to display them
- [ ] Founder/team story, if they want an About section

## Before launch
- [ ] Replace all demo imagery
- [ ] Remove or clearly label demo projects
- [ ] Test every phone and navigation link
- [ ] Test mobile menu and booking UI
- [ ] Confirm all copy and prices with the client
- [ ] Confirm privacy notice and terms if the form is later connected to a real service
